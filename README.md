# Ritika Chaurasia — Sports Model Portfolio

A one-page sports / fitness / active-lifestyle model portfolio designed for GitHub Pages.

## Folder structure

- `index.html` — main page
- `style.css` — complete styling
- `script.js` — interactions and animations
- `assets/` — replace placeholder image files with your own photos

## Add your photos

Keep the filenames below:

- `hero.jpg` — strongest hero portrait / 3/4 athletic portrait
- `feature.jpg` — large performance image
- `sport-action.jpg` — cricket/sports action
- `fitness-training.jpg` — gym/training
- `activewear.jpg` — activewear campaign
- `lifestyle.jpg` — lifestyle/athleisure
- `outdoor.jpg` — outdoor fitness
- `editorial.jpg` — editorial portrait
- `profile.jpg` — clean agency-style portrait

Recommended: JPG/WebP, high quality, ideally 1600px+ on the long edge.

## Before publishing

1. Replace the placeholder images.
2. Update your height and other profile information in `index.html`.
3. Replace `your@email.com`.
4. Replace the Instagram URL.
5. Add your final comp card as `assets/ritika-comp-card.pdf`.
6. Upload the folder contents to a GitHub repository.
7. Enable GitHub Pages from Settings → Pages.

No backend or paid hosting is required.
