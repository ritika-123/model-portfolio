# Ritika Chaurasia — Clean Sports Model Portfolio

Minimal editorial design using warm off-white, charcoal and muted olive. Responsive one-page website with portfolio filters.

## Files
- `index.html` — page content
- `style.css` — styling
- `script.js` — category filter interactions
- `assets/` — sample AI-generated image references

## Before sharing with agencies
The included sample visuals are AI-generated pose/style references. Replace them with your own real photographs. Keep the same filenames in `assets/` to avoid editing the HTML.

Update `your@email.com`, Instagram URL, height, hair/eyes, shoe size and comp-card link in `index.html`. Then publish through GitHub Pages (Settings → Pages).
